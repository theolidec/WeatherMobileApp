# Core Weather

A beautiful and intuitive weather application providing real-time weather updates and forecasts.

## Features

- Real-time weather data
- Hourly and daily forecasts
- Location search with history
- Dark/Light theme support
- Multi-language support (English, Swedish, Spanish)
- Customizable units (temperature, speed, precipitation)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/theolidec/WeatherMobileApp.git
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

## Requirements

- Flutter 3.19.0+
- Dart 3.8.1+
